# SCET 理论审阅与下一轮实验设计

日期：2026-11-08。对象：用户提供的 SCET（Stopping-time Consistent Event-Time Control）方案。

## 判断

建议采纳跨执行前缀的停时一致性作为下一轮核心假设。已有项目理论已经包含事件核、options、条件风险预算及事件 Bellman 递推；本提案的主要增量是把事件年龄、真实执行历史和剩余事件预测绑定起来，并训练它们跨前缀一致。

这是一项学习与表示假设：在相同可用历史、容量、数据和规划预算下，这种约束是否改善条件预测与闭环决策。它不是事件规划相对于正确逐步规划的普遍表达能力优势。

## 最简数学骨架

设 H_j 为执行到 j 的实际观测—动作历史，m 为固定闭环控制器，τ 为从本次启动时刻计算的停时。对事件端点测试函数 f，定义

    F_f(H_j) = E[γ^(τ-j) f(E,H_τ) | H_j, τ>j, m]。

这里恢复的是同一控制器实例、同一终止规则和原有剩余期限。若原最长持续时间为 4、已执行 3 步，恢复期限是 1；不能重新给 4 步。

令

    M_j = 1{τ≤j} γ^τ f(E,H_τ) + 1{τ>j} γ^j F_f(H_j)。

在同一概率模型及固定规则下，M_j 是条件期望构成的鞅，满足 E[M_(j+1)|H_j]=M_j。对有界测试函数及有限期限，可直接使用塔式法则。这个表达把“停时一致性”化为可以检验的条件矩约束。

实现时使用成对前缀，预测剩余时间、事件类别、后续可观测信息状态；联合训练：

    L = L_event-likelihood + λ_sc L_prefix-consistency + λ_v L_decision-tests。

一致性目标必须有真实事件/生存观测及端点监督作为锚点：常数预测也可能自洽，单独最小化一致性并不识别正确模型。随机轨迹上的两个目标不必逐样本相等；所要求的是条件期望相等。若测试函数依赖剩余期限或风险状态，必须把对应状态与递推一起携带。

## 需要落到实现里的四项修正

1. **RESUME 与 RESTART 区分。** 保存事件起点、控制器内部进度、终止规则版本、年龄、剩余期限和真实执行动作。重新发起一个控制器属于新的核。
2. **不发生事件也是观测。** 基于当前历史条件化整个联合核；只有单纯生存证据时才可简化为生存函数比值。出现新视觉证据后，不能只减去经过的时间。
3. **未来信息分支必须可观测。** 规划器不能根据隐藏的混合分量选择动作或风险预算；无法观测地区分的分支必须共享后续决策，或合并成同一信息状态。
4. **中断必须入模。** 安全接管不是独立随机删失；若它依赖危险状态，应作为实际闭环策略的一部分或显式事件记录，否则估计可能系统性忽略危险尾部。

## 理论界的定位

提案中的双占用误差界是合理的 Bellman 残差望远镜求和形式。需要同一控制器/可行策略类、正确终端值、有限期限及可实现的模型规划值；近似规划还要累计规划误差。约束问题中的不同风险可行集合不能直接套用无约束比较，必须保证比较策略在所用优化问题中可行，或单独处理可行集合偏差。

降低决策次数本身不保证更紧的界：更长事件的单次核误差可能上升。值得研究的是如何用可估计的决策误差选择事件尺度。风险递推则需要自己的概率上界及校准条件，不能从成本残差界自动推出。

## 已执行的精确诊断

代码：`check_mechanism.py`；输出：`MECHANISM_CHECK.json`。使用 Fraction 精确有理数。

- 原等待例子：一直等待成本 13；等到第 2 步再条件决策成本 22/5=4.4。
- 同历史信息的逐步动态规划与事件压缩规划都得到 4.4。
- 另 200 个随机离散到达时间模型中，两种规划的精确最优值相等。
- 这些例子的绕路成本固定，因此无新信息的间隔内延后绕路不会更优；不能外推为任意宏动作集合的等价定理。
- 双出口算例说明保留观测后决策的价值；它没有证明某个学习算法能恢复该后验。

以上是机制诊断，没有训练 SCET，也不是导航提升结果。

## 最小可区分实验

采用共同的历史编码器、输入、训练轨迹和控制器集合：

| 组别 | 预测模型 | 目的 |
|---|---|---|
| A | 有记忆的逐步模型 | 排除仅由记忆恢复带来的提升 |
| B | 联合事件时间—后续信息模型 | 测量事件表示本身的影响 |
| C | B 加跨前缀一致性损失 | 隔离核心训练机制 |

另保留事件年龄清零作为故障诊断，不把它当主要竞争基线。先在有限模型中验证终止、恢复、信息分支，再进行闭环学习实验。

至少覆盖三类环境：长尾等待与隐状态；主动观测后选路；机器人动作改变后续交互。第三类用来检验行动条件性，不能由当前独立行人轨迹场景代替。

使用多档数据量，比较事件条件概率、残余时间分布、决策动作排序、成功率/碰撞/耗时及真实规划时间。在同数据与容量比较之外，绘制质量—计算量曲线。只有 C 相对 B 的稳定收益，才能支持一致性机制；只有 B/C 相对强 A 的收益，才能支持事件模型路线。

第一轮固定控制器和终止规则，只训练事件头与记忆。价值证书触发、可学习停止规则和风险预算分配留作后续独立扩展，避免把首轮收益混在多项改动里。

## 与已有文献的关系

- StochSIPP 已使用到下一观测的宏动作及 AND/OR 条件规划，因此“事件驱动搜索”不是充分的新颖性依据。可区分点应落在学习历史依赖的联合核、跨执行前缀一致性及部分可观测条件下的表示与样本效率。https://arxiv.org/abs/2608.00792
- Value Equivalence 已提出围绕 Bellman 更新保留模型的决策相关性质。本方案可将测试函数具体化为停时事件、风险及期限敏感价值，但需要证明或实验展示这种具体化带来的收益。https://proceedings.neurips.cc/paper/2020/file/3bb585ea00014b0e3ebe4c6dd165a358-Paper.pdf
